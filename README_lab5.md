# Отчёт по лабораторной работе

**Тема:** Разработка системы управления курсами.

## Выполненная работа

- Реализованы регистрация, авторизация и роли пользователей.
- Добавлены CRUD-операции для курсов и преподавателей.
- Реализованы поиск, фильтрация и статистика.
- Добавлена валидация данных через `express-validator`.
- Настроена централизованная обработка ошибок.
- Реализовано логирование HTTP-запросов и действий администратора.
- Добавлены уведомления о создании курса через Socket.IO.
- Проверены права доступа, валидация и обработка ошибок.

## Вывод

В ходе работы создана система управления курсами и преподавателями. Реализованы основные функции, проверка данных, разграничение доступа, логирование и уведомления.

### Основные понятия

- **Express.js** - фреймворк для создания веб-сервера и маршрутов.
- **Middleware** - функция, которая выполняется между запросом и ответом сервера.
- **Router** - разделяет маршруты по функциональности.
- **MVC** - разделение приложения на Model, View и Controller.
- **Model** - описывает данные и работу с базой данных.
- **View (EJS)** - HTML-шаблон для отображения данных.
- **Controller** - обрабатывает запросы и вызывает нужные операции.
- **EJS** - шаблонизатор, позволяющий вставлять данные в HTML.
- **Sequelize** - ORM для работы с базой данных через JavaScript.
- **ORM** - позволяет работать с таблицами как с объектами.
- **CRUD** - Create, Read, Update, Delete: создание, чтение, изменение и удаление.
- **async/await** - удобный способ работать с асинхронными операциями.
- **try/catch** - перехватывает ошибки.
- **next(error)** - передаёт ошибку обработчику ошибок Express.
- **express-validator** - проверяет корректность введённых данных.
- **HTTP-статусы**:
  - `200` - запрос выполнен.
  - `302` - перенаправление.
  - `400` - некорректные данные.
  - `401` - требуется аутентификация.
  - `403` - доступ запрещён.
  - `404` - ресурс не найден.
  - `409` - конфликт данных.
  - `500` - внутренняя ошибка сервера.
- **Аутентификация** - проверка того, кто пользователь.
- **Авторизация** - проверка прав пользователя.
- **Session** - хранит данные о сессии пользователя между запросами.
- **bcrypt** - хеширует пароли для безопасного хранения.
- **Morgan** - записывает информацию об HTTP-запросах.
- **Socket.IO** - обеспечивает обмен событиями между сервером и клиентом в реальном времени.
- **`io.emit()`** - отправляет событие всем подключённым клиентам.
- **`express.static()`** - отдаёт статические файлы, например CSS и JavaScript.
- **`.env`** - файл для конфигурации и секретных параметров.
- **Логирование** - запись запросов, действий и ошибок для контроля работы приложения.
