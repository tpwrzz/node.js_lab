## 1. Тема и назначение проекта

Тема проекта — веб-приложение для управления библиотекой.

Приложение позволяет просматривать книги, авторов и жанры, искать и фильтровать книги, а также брать книги и возвращать их. Администратор может управлять каталогом и назначать книги пользователям. Также предусмотрена страница со статистикой библиотеки.

## 3. Модели и связи между ними

В проекте используются следующие модели:

- **User** — зарегистрированные пользователи. Содержит имя, email, пароль в виде хеша и роль (`user` или `admin`).
- **Book** — книги. Содержит название, количество страниц, описание, дату публикации и информацию о доступности.
- **Author** — авторы книг. Содержит имя, год рождения и год смерти.
- **Genre** — жанры книг.
- **TakenBooks** — история выдачи книг пользователям. Содержит пользователя, книгу, дату выдачи и дату возврата.

Связи между моделями:

- Один автор может иметь несколько книг, а каждая книга связана с одним автором.
- Один жанр может включать несколько книг, а каждая книга относится к одному жанру.
- Один пользователь может иметь несколько записей о выданных книгах.
- У одной книги может быть несколько записей в истории выдачи.
- Модели `User` и `Book` связаны через `TakenBooks`.

## 4. Установка и запуск

1. Установить Node.js и PostgreSQL.
2. Скачать или скопировать проект.
3. Открыть терминал в папке проекта.
4. Установить зависимости:

   ```bash
   npm install
   ```

5. Создать файл `.env` и указать параметры подключения к базе данных.
6. Создать базу данных PostgreSQL.
7. Запустить приложение командой:

   ```bash
   npm start
   ```

   Если в `package.json` нет команды `start`, необходимо использовать фактическую команду запуска проекта, например `node app.js`.

8. Открыть приложение в браузере по адресу, указанному в настройках сервера (например, `http://localhost:3000`).

## 5. Создание базы данных

В PostgreSQL создать базу данных:

```sql
CREATE DATABASE library_db;
```

Затем указать её название, пользователя и пароль в файле `.env`.

Модели проекта должны быть синхронизированы с базой данных способом, который используется в приложении. Если таблицы не создаются автоматически, необходимо выполнить используемые в проекте миграции или настроить синхронизацию Sequelize.

## 7. Основные маршруты

| Метод | Маршрут | Назначение |
|---|---|---|
| GET | `/` | Главная страница или страница авторизации |
| GET | `/books` | Просмотр списка книг |
| GET | `/books/:id` | Просмотр информации о книге, если маршрут предусмотрен |
| GET | `/authors` | Список авторов |
| GET | `/genres` | Список жанров |
| GET | `/statistics` | Статистика библиотеки |
| GET | `/register` | Форма регистрации |
| POST | `/register` | Регистрация пользователя |
| GET | `/login` | Форма входа |
| POST | `/login` | Авторизация |
| POST | `/logout` | Выход из аккаунта |

Для управления книгами, авторами и жанрами предусмотрены дополнительные маршруты создания, редактирования и удаления. Зарегистрированные пользователи могут брать и возвращать книги, а администратор — назначать книги пользователям и снимать их с пользователей.
